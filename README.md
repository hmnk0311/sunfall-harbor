Sunfall Harbor is an original top-down open-world crime game that plays in a desktop browser from static files — no build step, no network, no borrowed assets. Cruise a 3000×2300 harbour city of six named districts (Marina, Old Market, Neon Row, Dockyards, Hillcrest, Midtown) on foot or behind the wheel: steal cars, dodge or fight traffic, and run a four-mission campaign for fixer Marisol Vega — a package on Pier 9, a timed run across the bay, a golden coupe to borrow, and one last escape from a three-star chase. Crimes witnessed by pedestrians or the Sunfall PD raise your wanted stars; more stars bring more patrol cars that chase, ram and pin you until you are BUSTED, while hiding out drains the heat. A pistol with reloads, synthesised WebAudio engine/siren/gunshot sounds, a live minimap with police blips and mission markers, and a localStorage save (cash, mission, position) round it out.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Move and drive with WASD or the arrow keys, Shift to sprint, E/F to steal or enter a car and to exit, Space for the handbrake, mouse click or J to shoot, R to reload, P or Esc to pause. To hand the game in the way the grader does: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
